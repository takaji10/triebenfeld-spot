# triebenfeld-spot

Spot sheets for the von Triebenfeld edition (https://takaji10.github.io/triebenfeld-letters/):
readings the editor answers away from the desktop. Each build under sheets/<slug>/
is a self-contained page; the editor's answers come back into the working
session, are recorded in the holding's notes.md, and the sheet page here is
replaced or removed when its rows are settled.

The crops are cut from scans already published on the edition's own site.
